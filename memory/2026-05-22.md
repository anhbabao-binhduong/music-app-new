# 2026-05-22 — Phase 1 Realtime Chat MVP

## What was built
Complete end-to-end chat feature (1-to-1 DMs) added to the music app.

## Files created

### SQL Migration
- `supabase/migrations/20240001_create_chat_tables.sql`
  - Tables: `chat_conversations`, `chat_messages`
  - RLS policies for participant-only access
  - Trigger: `update_conversation_last_message` auto-updates `last_message_at`
  - ⚠️ Must be run manually in Supabase Dashboard SQL Editor
  - ⚠️ Must enable Realtime on `chat_messages` table in Supabase Table Editor

### Domain Layer
- `lib/domain/entities/chat_message_entity.dart` — Equatable, has `isOptimistic` getter
- `lib/domain/entities/chat_conversation_entity.dart` — Equatable
- `lib/domain/repositories/chat_repository.dart` — abstract contract with Either<Failure,T>

### Data Layer
- `lib/data/models/chat_message_model.dart` — fromJson/toEntity/toInsertJson
- `lib/data/repositories/chat_repository_impl.dart`
  - `findOrCreateConversation`: upsert with LEAST/GREATEST UUID ordering to satisfy UNIQUE constraint
  - `getMessages`: paginated, newest-first, cursor via `created_at`
  - `subscribeToMessages`: Supabase Realtime channel per conversation, stored in `_channels` map
  - `disposeChannel`: per-channel unsubscribe only (never `removeAllChannels`)

### State Management
- `lib/presentation/bloc/chat/chat_state.dart` — sealed: ChatInitial, ChatLoading, ChatLoaded, ChatError
- `lib/presentation/bloc/chat/chat_cubit.dart`
  - Optimistic send: temp ID `temp_${timestamp}`, prepend to list, rollback on failure
  - Realtime dedup: replace temp msg with real on matching content+senderId
  - `close()` cancels StreamSubscription AND disposes Supabase channel

### UI
- `lib/widgets/chat/chat_message_bubble.dart` — right/left alignment, clock icon for optimistic
- `lib/widgets/chat/chat_input_bar.dart` — gradient send button, SafeArea, disabled when empty/sending
- `lib/pages/chat/chat_page.dart` — BlocProvider+BlocListener, reverse ListView, scroll-to-load-more

### Wiring
- `lib/core/router/app_routes.dart` — added `static const chat = '/chat'`
- `lib/app.dart` — added route for `/chat` using `Navigator.onGenerateRoute`, reads `arguments` map
- `lib/core/di/service_locator.dart` — `ChatRepository` lazySingleton, `ChatCubit` registerFactoryParam
- `lib/pages/user_search/user_profile_view_page.dart` — added `_ChatActionButton` widget (gradient, hidden for own profile)

## Key decisions
- UUID ordering: `LEAST(p1, p2)` stored as `participant_1_id` to satisfy UNIQUE constraint
- Realtime: one channel per conversation, stored in `Map<String, RealtimeChannel>` to allow targeted dispose
- DI: `ChatCubit` uses `registerFactoryParam<ChatCubit, String, String>` (conversationId + currentUserId)
- Navigation from profile: `Navigator.of(context).pushNamed(AppRoutes.chat, arguments: {...})`
