# Phase 2 — Chat Conversations Inbox + Polish

## Changes Made

### Step 1: ChatRepository + ChatRepositoryImpl
- Added 3 methods to `ChatRepository` abstract: `getConversations()`, `subscribeToConversationUpdates()`, `disposeConversationsChannel()`
- Implemented in `ChatRepositoryImpl`:
  - `getConversations()`: queries chat_conversations + profiles + last message preview
  - `subscribeToConversationUpdates()`: realtime channel for INSERT/UPDATE on chat_conversations
  - `disposeConversationsChannel()`: unsubscribe channel individually

### Step 2: ConversationsState + ConversationsCubit
- `lib/presentation/bloc/conversations/conversations_state.dart` — sealed class with Initial, Loading, Loaded, Error
- `lib/presentation/bloc/conversations/conversations_cubit.dart` — init(), _loadConversations(), subscribe to updates
- Registered `ConversationsCubit` as factory in service_locator.dart

### Step 3: ConversationsPage
- `lib/pages/chat/conversations_page.dart` — list of conversations with avatar, name, preview, time
- Navigation to ChatPage on tap

### Step 4: Cursor Pagination
- Added `hasMore`, `isLoadingMore` to `ChatLoaded` state with `copyWith`
- Added `loadMore()` to ChatCubit — fetches older messages using cursor
- Added ScrollController to ChatPage — triggers loadMore on scroll near top
- Shows loading spinner at end of list when loading more

### Step 5: ChatNotificationService — Realtime
- Replaced Timer-based polling with Supabase Realtime channels
- `startListening()` subscribes to INSERT on chat_messages (new messages) and UPDATE (read status)
- Each event re-fetches unread count
- `disposeChannels()` unsubscribes individual channels
- Called `dispose()` before signOut in profile_tab logout handler

### Step 6: Wiring
- Added `AppRoutes.conversations = '/conversations'`
- Added route in app.dart → ConversationsPage
- Profile tab "Tin nhắn" now navigates to ConversationsPage instead of ChatPage

### Step 7: Bug Fixes (Conversations Inbox + Polish Sync)
- **Local Time Bug:** Verified and maintained `DateTime.tryParse(...).toLocal()` for `lastMessageAt` parsing in `ChatRepositoryImpl`.
- **Realtime / UI Sync Bug:** Added `subscribeToConversationUpdates()` listening to both `chat_conversations` and `chat_messages` inserts.
- **Read/Unread Tracking:**
  - Added `unreadCount` to `ChatConversationEntity`.
  - Added `markConversationRead()` in `ChatRepository` and implemented it in `ChatRepositoryImpl` (updates database is_read where sender != user).
  - Wired `markConversationRead()` into `ChatCubit.init()` and message reception.
  - Corrected global unread calculation query in `ChatNotificationService` to only check inside active conversation IDs.
  - Implemented unread badges, bold text styles for conversations with unread messages in `ConversationsPage`.

### Step 8: Debug + Badge Fix Follow-up
- Added temporary debug logging in `lib/services/chat_notification_service.dart` to print:
  - current `uid`
  - raw `chat_conversations` result
  - resolved `convIds`
  - raw unread query result
  - final unread badge value
- Added temporary debug logging in `lib/data/repositories/chat_repository_impl.dart` for `markConversationRead()` to print:
  - `conversationId`
  - current `uid`
  - updated row count / raw updated rows
  - any caught exception + stack trace
- Verified from code flow:
  - `ChatPage` creates `ChatCubit` and calls `init()`
  - `ChatCubit.init()` calls `_repo.markConversationRead(conversationId)` then `ChatNotificationService.refresh()`
  - profile badge is driven by `ChatNotificationService.unreadCount`
- Found stale conversation badge cause:
  - `subscribeToConversationUpdates()` previously listened to `INSERT` only on `chat_messages`
  - read-status changes are `UPDATE`, so conversations list could stay stale after opening a chat
- Fixed conversation-list refresh by:
  - changing `chat_messages` realtime listener in `ChatRepositoryImpl.subscribeToConversationUpdates()` from `PostgresChangeEvent.insert` to `PostgresChangeEvent.all`
  - reloading `ConversationsCubit` after returning from `ChatPage` in `lib/pages/chat/conversations_page.dart`
